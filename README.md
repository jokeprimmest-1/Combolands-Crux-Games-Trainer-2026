## 🎮 About the Game

Combolands: Roguelike Citybuilder is a single-player indie strategy game developed by Crux Games and released on August 24, 2026. It combines citybuilding, deckbuilding, turn-based strategy, procedural generation, and roguelike progression.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Combolands: Roguelike Citybuilder**. This trainer provides optional quality-of-life controls for building runs on procedurally generated islands. It can assist with gold, rerolls, building selections, combo scoring, potions, guild progression, and run management while preserving the game's placement and synergy-based strategy.

**Target Audience:** Players who want to experiment with building layouts, guild combinations, procedural islands, potions, and high-scoring combo strategies while reducing repetitive resource and progression limitations.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

The game is controlled through menus and board interactions rather than character movement. Select buildings, options, and tiles with the mouse or supported controller input. Trainer movement enhancements are not applicable.

### Tools & Inventory

There is no traditional character inventory. Buildings, building offers, potions, quests, guild choices, and other run resources are managed through the game's deckbuilding and citybuilding interfaces. Activate related trainer options before spending gold or consuming limited-use items.

### World & Environment

Each run takes place on a procedurally generated island. Choose two guilds, place buildings on available terrain, and develop a compact metropolis by combining adjacency effects and building synergies. Use score, gold, rerolls, building control, and guild progression features to test different strategies across runs.

### Combat & Weapons

Combolands has no conventional combat mode. Progress is based on turn-based placement, resource management, milestones, guild combinations, and cascading score combos. Combat-related trainer options are therefore unnecessary.
